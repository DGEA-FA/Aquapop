# DynapopQC
AquaPop est une application conçue pour automatiser les analyses les plus couramment utilisées pour décrire une population de poissons. 
Les analyses s’appliquent aux pêches expérimentales normalisées au touladi, au doré jaune et à l’omble de fontaine (PENT, PENDJ, PENOF). 
Les comparaisons spatiales et temporelles ne sont pas abordées dans cette version de l’outil.
Les analyses respectent les recommandations du Tome II du Guide de normalisation des inventaires en eaux intérieures (document non publié) et le Guide pour la réalisation d’analyses statistiques en faune aquatique à l’aide du logiciel R (Mainguy 2023, version 1.3). 
Pour des questions sur les fondements théoriques et les recommandations, vous êtes invités à consulter ces documents.
